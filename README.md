# DearData100 Project
## Fitness Data Visualisation

This project is a creative coding data visualisation created using Processing. The aim of the project is to collect personal fitness data over a long period of time and transform it into an interactive visual experience.

The dataset consists of daily fitness information recorded using the Apple Health app. For each day, I collected three pieces of data:

- Daily steps
- Distance travelled (km)
- Energy burned (calories)


The data is stored in a CSV file and loaded directly into the Processing sketch. This allows the visualisation to update automatically whenever new data is added, without requiring changes to the code.

Currently, the project visualises daily step counts using a bar chart. Each bar represents a single day and is scaled relative to the values in the dataset. Users can hover over bars to display the exact number of steps recorded for that day.


---
### Features:
- Automatic CSV data loading
- Data-driven bar chart
- Responsive graph sizing based on dataset length
- Hover interaction displaying fitness values
- Dynamic labels and graph scaling
- Built using Processing (Java)
